# Single Price Grid Component

A responsive solution to the Frontend Mentor Single Price Grid Component challenge.

## Overview

This component combines a clear pricing offer, subscription call to action, and supporting benefits in a responsive two-column layout.

## Built With

- Semantic HTML5
- Modern CSS
- CSS Grid
- Responsive design
- Accessible focus states
